/**
 * POST /api/coa/claim
 *
 * "Accept Gift" claim endpoint for the Certificate of Authenticity flow.
 * The viewer (already authenticated via the standard WhatsApp-OTP / passkey
 * sign-in flow) claims ownership of a physical card by its NFC serial.
 *
 * Trust model: bearer-asset. Whoever holds the card (and therefore knows
 * the serial) can claim. No buyer-side approval required. Matches the
 * cultural model of physical gold gifting + matches Mukesh's product brief
 * 2026-05-18.
 *
 * Body: { serial: string }
 *
 * Flow:
 *   1. Verify auth (Supabase session cookie)
 *   2. Rate-limit per user (3 claims per 10min — prevents bot enumeration)
 *   3. Atomic ownership transfer via claim_card_gift() RPC (FOR UPDATE lock)
 *   4. Look up previous owner's first name (giver) + claimant's name/last-4
 *      (the latter only for the giver's thank-you template variable)
 *   5. Send WhatsApp template to previous owner (TEMPLATE_GIFT_ACCEPTED)
 *   6. Return { ok, previousOwnerFirstName } so the UI can show the giver's
 *      first name to the claimant (phone last-4 is no longer surfaced)
 *
 * Error cases:
 *   - 401: not authenticated
 *   - 400: missing/invalid serial
 *   - 404: serial unknown
 *   - 409: claimant is already the current owner (self-gift)
 *   - 410: card has no current owner (unassigned/voided)
 *   - 429: rate-limited
 *   - 500: DB / WhatsApp failure (transfer still completed if RPC succeeded;
 *          thank-you message is fire-and-forget)
 */
