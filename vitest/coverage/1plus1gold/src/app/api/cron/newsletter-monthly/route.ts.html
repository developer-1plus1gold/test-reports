/**
 * GET /api/cron/newsletter-monthly
 *
 * 1st of month, 09:00 SGT (= 01:00 UTC). Runs the monthly newsletter
 * pipeline up through compliance check; then halts and waits for Mukesh.
 *
 *   1. Aggregate prior-month market data (price + WGC inputs)
 *   2. Run market_education_agent (Opus) → MarketBrief JSON
 *   3. Compose canonical English markdown + sample customer blocks
 *   4. Run newsletter_compliance (Haiku) → pass/fail + flags
 *   5. Insert newsletter_market_briefs row with appropriate status:
 *        pass → 'awaiting_publish' (Mukesh types founder note + clicks Publish)
 *        fail → 'compliance_pending' (admin queue)
 *   6. Send Mukesh a WhatsApp ops alert

 * No customer-side activity. That happens at view time via /account/newsletter.
 *

 * re-generating. Use ?force=1 to bypass (admin manual re-run).
