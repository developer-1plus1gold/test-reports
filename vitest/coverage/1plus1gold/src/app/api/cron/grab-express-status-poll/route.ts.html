/**
 * POST|GET /api/cron/grab-express-status-poll — every 5 minutes (2026-11-07).
 *
 * Converges every live GrabExpress API trip to what Grab's own authenticated
 * API (Get Delivery Details) reports. The Tracking Webhook is the low-latency
 * path; this is the spine, exactly as spx-status-poll and lalamove-status-poll
 * are for theirs: a lost or rejected webhook can never leave a delivered
 * parcel's bars unsold.
 *
 * Until the API credentials are set it does nothing and says so (the run is
 * still recorded, so a silent cron is never mistaken for a working one).
 *
 * Covers: shipper 'grab' with a deliveryID (API-booked only — a hand-booked
 * trip has none), not delivered/failed, created in the last 3 days. GrabExpress
 * is same-day; scheduled trips are at most 2 days ahead.
 */
