 *
 *   GET  /api/admin/orders/[id]/split-invoice
 *        → the order's lines (with order_item ids) + order-level charges, for the
 *          admin split-builder UI.
 *
 *   POST /api/admin/orders/[id]/split-invoice
 *        Body: { plan: { groups: [{ slices: [{orderItemId, quantity}] }], mode },
 *                send?: boolean }
 *        → builds ONE PDF: page 1 = the original invoice (unchanged), then one
 *          page per distributed invoice. `send:true` emails it to the customer as
 *          an attachment; otherwise the PDF is returned for download.
 *
 * RENDER-ONLY: nothing about the order / payment / ledger is touched. This route
