 *   GET   /api/admin/governance/breaches        → list, newest first
 *   POST  /api/admin/governance/breaches        → log a new incident
 *   PATCH /api/admin/governance/breaches?id=…    → update / advance status
 *
 * Admin-only (checkAdminAuth) + rate-limited. Service-role client (the register

 * timestamps are applied here rather than trusting arbitrary client fields:
