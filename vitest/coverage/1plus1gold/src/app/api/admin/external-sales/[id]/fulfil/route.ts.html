 * "deliver" we flip reserved inventory → sold (COGS) and complete the order
 * (revenue@DELIVERY) — mirroring the self-pickup mark-pickup path.

// Strip control chars + Unicode bidi overrides before storing free text. These
// values land in the admin panel, on the customer's order view and in receipts /
// log lines; a U+202E can visually reverse text and a newline can forge a second
// log line. Nothing legitimate in a name, address or waybill needs them.
function cleanText(s: unknown): string {
  return String(s ?? "")
    .replace(/[\u0000-\u001F\u007F]/g, "")                    // C0 controls + DEL (newline, NUL)
    .replace(/[\u200E\u200F\u202A-\u202E\u2066-\u2069]/g, "") // bidi marks + overrides
    .trim();
}
