/**
 * Generic supplier management — the add/edit-supplier flow for the Supplier &
 * Pricing hub (Step 2, see docs/supplier-pricing-hub-design.md). Until this
 * route existed, suppliers could only be seeded by migration; the app was
 * effectively single-supplier (MTB) with BullionKing bolted on.
 *
 * GET  /api/admin/pricing/suppliers/manage
 *   → { suppliers: [{ id, name, slug, pricingModel, premiumPct, isActive,
 *                      isConsignmentSource, consignmentSpreadPerGSgd, fetchMode,
 *                      fees: { flatFeeUsd, perGramFeeUsd, wireFeeUsd, fxMarkupSgdPerUsd } }] }
 * POST /api/admin/pricing/suppliers/manage
 *   { name, slug, pricingModel: 'sheet'|'manual', isConsignmentSource? }     → creates
 * PUT  /api/admin/pricing/suppliers/manage
 *   { id, name?, pricingModel?, isConsignmentSource?, isActive? }            → edits
 *
 * Admin-only. The suppliers table is service-role RLS, so all writes go through
 * the service client here. Notes:
 *  - Two go-forward models (Supplier & Pricing hub redesign):
 *      · sheet  — a daily price sheet is uploaded (MTB). Landed fees on Pricing Settings.
 *      · manual — each product is priced by a per-product term ($ per piece or %
 *        over spot) set on the Premiums & Stock screen. No supplier-wide premium.
 *    The legacy `premium_pct` (one number for every product) and `consignment_formula`
 *    models are retired — 20260725c collapsed existing suppliers onto `manual`.
 *  - `is_consignment_source` is ORTHOGONAL to the model: it turns on holding the
 *    supplier's stock + selling before procuring (inventory is set per-product on
 *    Premiums & Stock). Only meaningful for a `manual` supplier, so it's forced
 *    off when the model is `sheet`.
 *  - slug is IMMUTABLE after create — sheets, snapshots and favourites are keyed
 *    by slug, so changing it would orphan them. Create picks the slug; PUT can't.
 *  - No hard delete — FKs (supplier_prices, orders, snapshots) reference a
 *    supplier. Deactivate via isActive instead.
 *  - Landed fees (supplier_cost_config) are NOT written here — Pricing Settings
 *    (/api/admin/pricing/suppliers/config) is their single owner. GET still reads
 *    them back (read-only) for display context.
 */
