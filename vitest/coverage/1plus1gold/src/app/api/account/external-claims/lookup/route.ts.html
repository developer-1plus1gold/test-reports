/**
 * POST /api/account/external-claims/lookup
 *
 * Step 1 of the customer-facing "claim my marketplace order" funnel. The buyer
 * enters their marketplace order number + delivery postal code + buyer id; we look for a
 * matching, still-unclaimed external order and return a minimal preview so they
 * can confirm it's theirs before submitting the claim for admin approval.
 *
 * A no-match returns a generic result (no field-level oracle — an attacker must
 * not be able to probe which of order-number / amount / id was wrong).
 *
 * Body: { channel, orderNumber, postalCode, buyerLabel }
 * Errors: 401 unauth · 400 bad body · 429 rate-limited
