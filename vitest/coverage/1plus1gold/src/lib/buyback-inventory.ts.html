/**
 * Ordinary (non-vault, non-MAG) buyback → our stock.
 *
 * On approval we hold the bar, so each eligible buyback line becomes one
 * `inventory` row (source 'buyback'). The bar's NFC card must come back with
 * it: until 2026-11-20 this path never released the card, so it stayed
 * 'assigned' to the seller and packing refused it for the next buyer (D214179,
 * buyback 952ffe2a). The vault path has done this since 2026-10-26
 * (`releaseBoughtBackSerials`); this is the same rule for bars the customer
 * held themselves.
 *
 * Release rule (never release a card the customer still holds): every card
 * still assigned to the line's order item is released only when the line
 * sells back at least that many units. A line selling back 1 of 3 releases
 * nothing — we cannot tell which card came back — and logs it instead.
 *
 * When exactly one card is released, the new stock row carries its serials,
 * so the bar is traceable and packing finds it by its manufacturer serial.
 *
 * Best-effort: errors are logged and never fail the approval.
 */
