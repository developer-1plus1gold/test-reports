/**
 * The Right Time — one server-side cache shared by GET /api/right-time and
 * the server-rendered /charts/analytics page, so the page can ship its data
 * inside the HTML instead of waiting on a client fetch (Mukesh 2026-10-07:
 * "data loading of all the charts is very slow").
 *
 * Stale-while-revalidate: stale data is returned IMMEDIATELY and a single
 * refresh runs in the background; only a cold instance (no data yet) waits on
 * the query. The query reads whole tables, so it must never run per visit.
 *
 * Insights ("what this means" lines) are layered on top: the deterministic
