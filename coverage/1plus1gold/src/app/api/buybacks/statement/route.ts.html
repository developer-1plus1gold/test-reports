/**
 * GET /api/buybacks/statement?id=<buyback request id>[&token=<pdf token>]
 *
 * Renders the buyback statement PDF for the GROUP the request belongs to
 * (docs/buyback-statement-design.md): per-bar vault sell-backs sharing a
 * payout reference, or a MAG order, are one statement. The PDF itself is
 * built by `buildBuybackStatement` (shared with the admin send route).
 *
 * Access — any one of:
 *   - the owning customer (cookie or Bearer, getUserFromRequest)
 *   - an admin (checkAdminAuth)
 *   - a short-lived HMAC token (resource "buyback_statement", bound to this id)
 *     so the iOS app can open it in Safari, which carries no session.
 * A request the caller does not own is 404, not 403 (no existence oracle).
 */
