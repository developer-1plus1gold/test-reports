/**
 * GET /api/account/identities
 *
 * Returns the unified "sign-in methods" view for the authenticated
 * customer. Combines three sources into one list:
 *
 *   • auth.users.identities  → OAuth providers (apple, google) + email
 *   • profiles.phone         → WhatsApp number presence
 *   • webauthn_credentials   → passkey count
 *
 * Each item: { kind, label, value (redacted/last4), linked_at, removable }
 *
 * `removable` is false for any identity that would leave the user with
 * zero ways to sign in. The UI uses this to disable the Remove button on
 * the last identity. Removal itself happens via:
 *   - OAuth: DELETE /api/account/identities/:identity_id  (this file)
 *   - Phone: existing /api/admin/phone-change-requests CS-mediated flow
 *   - Email: not exposed in v1 (contact support)
 *   - Passkey: existing /api/account/passkeys/:id DELETE
 */
