/**
 * GET /api/admin/marketing/tiktok/callback/?auth_code=…&state=… — TikTok's redirect back.
 * (Registered WITH the trailing slash, as TikTok requires; Next.js serves it here.)
 *
 * ▶ WHY THIS ROUTE DOES NOT CALL checkAdminAuth. The admin cookie is SameSite=strict and
 * is not sent on a navigation coming from another site (tiktok.com), so requiring it
 * would fail every Connect. The proof is the `state` instead: 256 random bits, issued
 * only to a signed-in admin by /connect, stored as a hash, valid 10 minutes and burned
 * on first use. A request without a live state does nothing at all (same as Lazada).
 */
