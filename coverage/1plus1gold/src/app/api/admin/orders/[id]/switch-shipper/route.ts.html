/**
 * POST /api/admin/orders/[id]/switch-shipper
 * Header: x-admin-secret (admin-gated)
 *
 * ONE-WAY switch of an order's shipper from NinjaVan OR SPX → Lalamove — a
 * service UPGRADE (Lalamove is same-day/on-demand vs NinjaVan/SPX next-day). We
 * deliberately support only this direction.
 *
 * Works whether or not the source carrier is booked:
 *  - Unbooked (shipper_order_id null): just flip the carrier fields.
 *  - Booked (shipper_order_id set): CANCEL the live booking on the SOURCE
 *    carrier first (NinjaVan Order API, or SPX batch_cancel_order) so the parcel
 *    can't be collected by BOTH carriers, THEN flip. If the source cancel fails,
 *    we do NOT switch.
 * The order must still be `ninjavan` or `spx` + non-terminal.
 *
 * The switch flips the carrier fields and keeps `shipper_status='pending'` so the
 * order drops into the existing "Lalamove — Awaiting booking" tile, where the
 * operator books it via /book-delivery (which fetches a fresh distance quote and
 * ABSORBS any fee delta — the customer is never re-charged for the upgrade).
