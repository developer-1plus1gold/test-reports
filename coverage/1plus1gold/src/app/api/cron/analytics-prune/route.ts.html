/**
 * GET /api/cron/analytics-prune — enforces the 14-month analytics retention
 * (Measurement spec §05/§10). Deletes raw events + session roll-ups older than
 * the window, bounding table growth and privacy exposure (and giving the
 * unauthenticated /api/track ingest a hard upper bound). CRON_SECRET-gated.
 *
 * Deletes in bounded batches so a large backlog never holds a long lock.
 * ai_answer_probes + search_console_daily are weekly/daily-small and not pruned
 * here.
 *
 * Also enforces a short retention on `spx_webhook_captures` — the SPX inbound-
 * webhook debug ledger (raw body + signing headers). That table is a temporary
 * forensic aid, not order state; a 30-day window bounds its growth and shrinks
 * the PII/credential-exposure surface should its service-role RLS ever regress
 * (sec findings 8c20af68 / 91d5725f). Same batched helper, no new plumbing.
