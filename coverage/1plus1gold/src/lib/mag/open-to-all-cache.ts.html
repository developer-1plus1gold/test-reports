 *

 * client-side /api/mag/access fetch, so it popped in after the page painted
 * (operator report 2026-09-28). The only GLOBAL input is this switch, so it is
 * read server-side through the same L1 primitive as the carousel — a warm
 * instance pays nothing, and the note is in the first paint. The per-customer
 * part (an enabled customer can buy) is still answered client-side, and can
 * only HIDE the note, never make it appear late.
