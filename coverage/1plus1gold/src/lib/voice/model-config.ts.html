/**
 * Single source of truth for the active OpenAI voice models.
 *
 * Reads the `voice_model_config` table (one row per service: realtime /
 * transcribe / tts) so the model the live Realtime session uses — and the
 * defaults the /admin/voice-test harness shows — both come from the same
 * place the admin edits at /admin/voice-usage. No code change to swap a model.
 *
 * FAIL-OPEN: voice is customer-facing and latency-sensitive. If the table is
 * unreachable, empty, or a row is disabled, we fall back to the known-good GA
 * defaults rather than break the session. The env var OPENAI_REALTIME_MODEL is
 * applied by the caller as an even-higher-priority emergency override (so an
 * incident can roll the model back without a DB write or deploy).
